# answer-sheet — 4択模試の解答用紙 Webアプリ

紙の問題集で模擬テストを解くときに使う、**ブラウザで動く4択マークシート（解答用紙）**です。
選択肢をタップして解答を入力し、**名前をつけて保存**。あとから一覧で呼び出して**自己採点**できます。

- サーバーもデータベースも使いません（保存先はブラウザの localStorage とファイル）
- `index.html` ひとつだけの構成。ビルド・インストール不要
- スマホ縦画面に最適化、ダークモード対応

## 使いかた

1. アプリを開く（PC ならファイルをダブルクリック、スマホなら下の「ブラウザから使う」を参照）
2. **タイトル**（例：応用情報 模試① 科目A）・問題数・選択肢の表記（`1 2 3 4` / `A B C D` / `ア イ ウ エ`）を入れて「作成して解答をはじめる」
3. 各問の選択肢をタップして解答（**同じ選択肢をもう一度タップで取り消し**）。タップのたびに自動保存され、画面右上に「保存済み hh:mm」と出ます
4. 名前を変えたいときは「名前をつけて保存」。控えを残したいときは「別名で保存（コピー）」
5. 採点するときは「正解を入力」に切り替えて正解を入力し、「採点する」

## 保存と呼び出し

| やりたいこと | 操作 |
| --- | --- |
| 名前をつけて保存 | 解答画面の「名前をつけて保存」（内容は常に自動保存されます） |
| 保存した解答を呼び出す | トップの「保存した解答を呼び出す」一覧から「開く」。名前でしぼり込みもできます |
| 控えを残す | 「別名で保存（コピー）」＝解答も正解もそのままコピー |
| 同じ模試をもう一度解く | 「再挑戦用にコピー（正解だけ引き継ぐ）」＝正解はそのまま、解答は空で新規作成 |
| 一覧での整理 | 各行の「名前を変更」「複製」「削除」 |
| 別の端末へ移す・バックアップ | 「ファイルに保存（JSON）」「すべてファイルに保存（JSON）」→ 移行先で「ファイルから読み込む」 |
| 紙やExcelで見直す | 「CSVに書き出し」（問題番号・解答・正解・正誤・見直しフラグ） |

一覧には状態バッジ（未解答／解答中／解答ずみ、正解入力ずみ／正答率）と更新日時が出るので、どの模試が採点済みかひと目で分かります。

## そのほかの機能

- **自己採点** — 正答数・正答率・未解答数・所要時間を表示。まちがえた問題番号をタップするとその問題へジャンプ
- **見直しフラグ（⚑）** — あとで見直したい問題に付箋
- **進捗バー**と「未解答へ」ボタン — 最初の空欄へ移動
- **タイマー** — 解答にかかった時間を計測（開始／一時停止）
- **問題数の変更** — 「問題を10問ふやす」「問題数を変更」で後から調整

## ブラウザから使う（GitHub Pages）

このリポジトリには GitHub Pages への公開用ワークフロー（`.github/workflows/pages.yml`）が入っています。

1. このブランチを `main` にマージする（`main` への push でワークフローが動きます）
2. `https://<ユーザー名>.github.io/answer-sheet/` で開けるようになります

Pages が未設定のリポジトリでもワークフロー側から有効化します（`configure-pages` の `enablement: true`）。
うまくいかない場合は **Settings → Pages** で Source を **GitHub Actions** に設定してから、
Actions タブで「Deploy to GitHub Pages」を Re-run してください。

スマホのブラウザでそのURLを開き、ホーム画面に追加しておくとアプリのように使えます。
（公開したくない場合は、`index.html` を端末に保存してブラウザで開くだけでも同じように動きます。）

## データの保存場所について

解答データは開いた**端末・ブラウザの中だけ**に保存され、サーバーへは送信されません。

- 端末・ブラウザを変えるときは「ファイルに保存（JSON）」→「ファイルから読み込む」
- プライベートブラウズやサイトデータの削除では消えることがあります。大事な記録はファイルに保存しておいてください
