# answer-sheet — 4択模試の解答用紙アプリ

紙の問題集で模擬テストを解くときに使う、**4択のマークシート（解答用紙）アプリ**です。
アプリ上で選択肢をタップして解答を記録し、ブラウザに自動保存します。

`index.html` ひとつだけの構成で、インストールもビルドも不要です。

## 使いかた

1. `index.html` をブラウザで開く（スマホなら後述の GitHub Pages が便利です）
2. タイトル・問題数・選択肢の表記（`1 2 3 4` / `A B C D` / `ア イ ウ エ`）を決めて「作成して解答をはじめる」
3. 各問の選択肢をタップして解答する（**同じ選択肢をもう一度タップすると取り消し**）
4. 解いたあと「正解を入力」に切り替えて解答例を入力し、「採点する」で自己採点

## できること

- **解答の記録と自動保存** — タップするたびに端末のブラウザ（localStorage）へ保存。閉じても消えません
- **複数の解答用紙を管理** — 模試ごとに作成し、一覧から開き直せます
- **自己採点** — 正解を入力すると、正答数・正答率・まちがえた問題の一覧を表示。まちがえた問題番号をタップするとその問題へ移動します
- **見直しフラグ（⚑）** — あとで見直したい問題に付箋を付けられます
- **解答状況の表示** — 画面下に「◯ / ◯ 問 解答済み」と進捗バー。「未解答へ」で最初の空欄へジャンプ
- **タイマー** — 解答にかかった時間を計測（開始／一時停止）
- **問題数の変更** — 「問題を10問ふやす」「名前と問題数を変更」で後から調整可能
- **書き出し / 読み込み** — 1件ずつ JSON・CSV で書き出し、全件 JSON でバックアップ。JSON は読み込みで復元できます（端末の乗り換え用）
- スマホ縦画面に最適化、ダークモード対応

## スマホで使う（GitHub Pages）

リポジトリの **Settings → Pages** で、Source を `Deploy from a branch`、Branch をこのブランチ（または `main`）の `/ (root)` に設定すると、
`https://<ユーザー名>.github.io/answer-sheet/` で開けます。スマホのホーム画面に追加しておくとアプリのように使えます。

## データの保存場所について

解答データは開いた**端末・ブラウザの中だけ**に保存されます（サーバーへは送信されません）。

- 別の端末やブラウザへ移すときは「JSONで書き出し」→「JSONを読み込み」
- プライベートブラウズやサイトデータの削除では消えることがあります。大事な記録は書き出しておいてください
